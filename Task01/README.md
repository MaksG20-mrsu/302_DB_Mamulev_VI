# Task01

## Структура данных

### `movies.csv`
CSV-файл с информацией о фильмах. Колонки:
- `movieId` — идентификатор фильма;
- `title` — название фильма;
- `genres` — жанры, разделённые символом `|`.

### `ratings.csv`
CSV-файл с оценками пользователей. Колонки:
- `userId` — идентификатор пользователя;
- `movieId` — идентификатор фильма;
- `rating` — оценка от 0.5 до 5.0;
- `timestamp` — время выставления оценки в формате Unix.

### `tags.csv`
CSV-файл с пользовательскими тегами. Колонки:
- `userId` — идентификатор пользователя;
- `movieId` — идентификатор фильма;
- `tag` — текстовый тег;
- `timestamp` — время добавления тега в формате Unix.

### `occupation.txt`
Текстовый файл со списком профессий. Одна профессия на строку.

### `genres.txt`
Текстовый файл со списком жанров фильмов. Один жанр на строку.

### `users.txt`
Текстовый файл с данными пользователей. Поля разделены символом `|`:
- `userId` — идентификатор пользователя;
- `name` — имя;
- `email` — электронная почта;
- `gender` — пол;
- `registration_date` — дата регистрации;
- `occupation` — профессия.

### `ratings_count.txt`
Сводка по `ratings.csv`:
- минимальный `userId` и количество его оценок;
- максимальный `userId` и количество его оценок.

### `sqlite.txt`
Информация о версии SQLite и доступных режимах вывода в `sqlite3`.
